# WanderLuxe – Luxury Travel Planner

WanderLuxe is a luxury travel planning web application designed to help users explore premium destinations, discover luxury hotels, create personalized travel itineraries, and manage memorable travel experiences in one place.

This project provides an elegant and interactive user interface with destination browsing, hotel booking simulation, travel planning, and memory vault features.

## Features

* Luxury destination exploration
* Detailed destination pages with attractions and travel information
* Premium hotel listings with booking simulation
* Personalized trip planner
* Travel guide recommendations
* Booking management system
* Travel memory vault
* Responsive modern UI design
* Light and Dark theme support
* Simulated Spring Boot backend API structure
* JWT-based login simulation

## Technologies Used

* HTML5
* CSS3
* JavaScript
* React (CDN-based)
* Babel
* Simulated Spring Boot REST API structure
